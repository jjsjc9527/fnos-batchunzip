# 批量解压（飞牛 fnOS 应用）

网页版批量解压工具，打包成飞牛原生应用（.fpk），装好后在飞牛桌面上点图标就能打开。

## 功能

- 格式：zip、rar（含 RAR5）、7z、tar、tar.gz/tgz、tar.bz2、tar.xz、tar.zst、gz、bz2、xz
- 分卷：xxx.part1.rar、xxx.7z.001、xxx.zip.001、xxx.rar + .r00、xxx.zip + .z01，只显示第一卷，自动带上其他分卷
- 浏览文件夹、勾选多个压缩包一起解压；“包含子文件夹”可一次找出所有压缩包
- 中文文件名乱码（Windows 打的 GBK zip）自动修复
- 密码本：遇到加密包按顺序逐个尝试；也可以解压时临时填写密码
- 智能目录：包里只有一个文件夹时不再多套一层
- 解压成功后：保留 / 移到指定文件夹 / 删除压缩包（含全部分卷）
- 记住解压过的包，不会重复解压
- 自动解压：定时检查指定文件夹（比如下载目录），等文件下载完、几分钟不再变化后自动解压
- 在飞牛文件管理器里右键压缩包，可以“用批量解压打开”
- 有访问密码，防止局域网里其他人随意操作文件
- 内置 7-Zip 24.09，不需要在 NAS 上另外安装任何东西

## 安装

1. 按你的 NAS 选安装包：普通 Intel/AMD 机器用 `batchunzip_<版本>_x86.fpk`，ARM 机器用 `batchunzip_<版本>_arm.fpk`
2. 飞牛 **应用中心 → 右上角「手动安装」**，选择 .fpk 文件
3. 装好后到 **设置 → 应用设置 → 批量解压**，给要处理的文件夹授权“读写”（比如下载文件夹）
4. 点桌面上的「批量解压」图标打开，第一次打开先设置访问密码

桌面图标通过飞牛自身端口的“同源网关”（`/cgi/ThirdParty/batchunzip/index.cgi/`）打开，所以在局域网、远程访问、手机飞牛 App 里都能用。
在局域网内也可以直接访问 `http://NAS地址:18660`。

## 说明

- 应用以飞牛为它创建的专用用户运行，只能访问你授权的文件夹。
- 解压出来的文件会设置成所有用户可读写，保证你在文件管理器里能正常移动、删除。
- 卸载时可以选择是否删除应用自己的设置；已解压的文件和压缩包不会被动。

## 自己编译

需要 Go 1.24+：

```bash
./build.sh            # 生成 dist/batchunzip_<版本>_x86.fpk 和 _arm.fpk
```

目录结构：

```
src/        Go 后端 + 网页界面（src/web/index.html，编译时嵌入程序）
fnos/       飞牛应用包文件：manifest、cmd 生命周期脚本、权限/资源配置、桌面入口、图标、卸载向导
fnos/ui/index.cgi  飞牛同源网关入口（必须叫 index.cgi），调用程序的 -cgi 模式转发到 127.0.0.1:18660
build.sh    编译并打包 fpk（会从 GitHub 下载 7-Zip）
```

本地调试：

```bash
cd src && go run . -port 18660 -data ./data -root /你的/测试/文件夹
```
